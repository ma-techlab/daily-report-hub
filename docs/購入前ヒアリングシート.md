## 3. 日報の報告項目

標準は以下の項目です。そのまま使えるかご確認ください。

| 項目 | 標準仕様 | 利用可否 |
|---|---|---|
| 営業日 | 日付 | そのまま／変更希望 |
| 予定食数 | 0以上の整数 | そのまま／変更希望 |
| 提供食数 | 0以上の整数 | そのまま／変更希望 |
| 残食数 | 0以上の整数、提供食数以下 | そのまま／変更希望 |
| 出勤人数 | 0以上の整数 | そのまま／変更希望 |
| 衛生点検 | 「すべて実施」／「未実施の項目あり」 | そのまま／変更希望 |
| 本部への相談 | 「なし」／「あり」 | そのまま／変更希望 |
| 連絡事項 | 自由記述・任意 | そのまま／変更希望 |
