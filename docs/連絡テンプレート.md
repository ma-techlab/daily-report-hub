# 店舗日報ハブ 連絡テンプレート

`[ ]` 内を案件に合わせて置き換えてください。未実施の動作は「確認済み」と書かず、未確認項目と次の操作を明記します。

## 1. 納品メッセージ

```text
[ご担当者名] 様

お世話になっております。
店舗日報ハブの納品準備が整いました。

■ 納品内容
・Google スプレッドシート：[ファイル名／URL]
・日報入力フォーム：[フォーム名／URL]
・操作手順書：[場所／URL]

■ 設定内容
・対象店舗：[店舗数／店舗名]
・未提出リマインド：[時間帯]
・週次まとめ：月曜日 [時間帯]
・残食率基準：[値]
・提供不足率基準：[値]
・本部通知先：[メールアドレス]
・DRY_RUN：[現在の値]

■ 確認結果
・確認済み：[フォーム入力／日報記録／修正／要対応／受付エラー／未提出／週次集計／テストメールの実施済み項目]
・未確認：[未確認項目。なければ「なし」]

実メールは、テスト宛先と開始日のご承認後にだけ有効にします。
ご確認の際は、別途お送りする検収項目を順にお試しください。
```

## 2. 検収依頼

```text
[ご担当者名] 様

お手数ですが、以下の検収をお願いいたします。本番データは使わず、「テスト店」など架空の値でご確認ください。

1. 日報フォームから通常のテスト日報を1件送信する
2. 「日報」に同じ内容が記録されたことを確認する
3. 同じ店舗・同じ営業日で送り直し、行が増えず修正回数が増えることを確認する
4. 衛生点検を「未実施の項目あり」で送信し、要対応の理由を確認する
5. 残食数が提供食数を超えるテスト回答が「受付エラー」に残ることを確認する
6. 「前週のまとめを作成」を実行し、定休日を除いた週次集計を確認する
7. 「送信ログ」の状態を確認する

テストメールの実送信は、次の宛先で間違いないことをご返信いただいた後に行います。
テスト宛先：[メールアドレス]

問題がなければ「上記を確認し、検収します」とご返信ください。
問題がある場合は、発生した操作、画面名、表示された文言をお知らせください。
```

## 3. 操作質問への基本返信

```text
[ご担当者名] 様

ご連絡ありがとうございます。
ご質問の内容は「[質問の要約]」と理解しました。

まず、[画面名：例「日報」シート／「送信ログ」シート／Apps Script「実行数」] を開いてください。
次に、[操作を1つだけ記載] し、[確認する値または表示] をご確認ください。

解決しない場合は、次の情報をお送りください。
・発生日時
・操作した画面名
・表示されたエラー文言
・「送信ログ」または「受付エラー」の該当行（個人情報は隠してください）

パスワードや認証コードは送らないでください。
```

## 4. よくある操作質問の返信例

### 日報を修正したい

```text
「店舗日報」フォームを開き、修正する日報と同じ店舗・同じ営業日を選んで、正しい内容を送信してください。「日報」の同じ行が上書きされ、修正回数が1増えます。
```

### メールが届かない

```text
「送信ログ」シートを開き、該当する件名の「状態」を確認してください。「DRY_RUN（未送信）」なら試験モード、「宛先なしのため未送信」なら宛先未設定です。「失敗：…」の場合は、その文言をそのままお知らせください。
```

### 店舗がフォームに出ない

```text
「店舗マスタ」シートを開き、該当店舗の「有効」が TRUE であることを確認してください。確認後、「日報ハブ」メニューから「フォームの店舗を更新」を実行してください。
```
